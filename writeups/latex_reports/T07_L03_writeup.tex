\section{1. Design}
\noindent
\textbf{Architecture \& Implementation:} Safety FSM computing NOAA Heat Index with 10-sample rolling trend filter. 3-second hysteresis filter for Warning (30C) and Danger (38C) states. 2-second continuous flame detection latches FIRE alarm into NVS and unlocks fail-safe door immediately. 2-second capacitive touch hold triggers PANIC alarm. Teacher tag silences buzzer only after flame clears.

\vspace{3pt}
\noindent
\textbf{System Dataflow:} ESP32-S3 Dual-Core SoC $\rightarrow$ GPIO Interfaced Sensors (RC522 RFID, DHT11, IR Flame, Touch Wire, Buzzer) $\rightarrow$ FreeRTOS Cooperative Tasks (SensorTask Core 1 @ 50ms, NetworkTask Core 0 @ 20ms) $\rightarrow$ Real-time State Machine $\rightarrow$ Local mDNS Web Server (\url{http://classroom-t07.local}) $\rightarrow$ Public HTTPS Express Cloud Server $\rightarrow$ Role-Based Dashboard.
