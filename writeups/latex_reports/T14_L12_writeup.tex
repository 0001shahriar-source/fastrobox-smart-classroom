\section{1. Design}
\noindent
\textbf{Architecture \& Implementation:} Full hardware and network resilience engine. Automatically switches to Bluetooth Low Energy (BLE) advertising SC-14-OFFLINE when Wi-Fi drops for >30s. Offline circular flash buffer retains >=30 minutes of telemetry (600+ records). Upon reconnection, records flush oldest-first with original timestamps intact. Recovers door, fire, and settings after power cuts.

\vspace{3pt}
\noindent
\textbf{System Dataflow:} ESP32-S3 Dual-Core SoC $\rightarrow$ GPIO Interfaced Sensors (RC522 RFID, DHT11, IR Flame, Touch Wire, Buzzer) $\rightarrow$ FreeRTOS Cooperative Tasks (SensorTask Core 1 @ 50ms, NetworkTask Core 0 @ 20ms) $\rightarrow$ Real-time State Machine $\rightarrow$ Local mDNS Web Server (\url{http://classroom-14.local}) $\rightarrow$ Public HTTPS Express Cloud Server $\rightarrow$ Role-Based Dashboard.
